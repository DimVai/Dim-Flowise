# Contribution policy

This is a personal fork maintained for the owner's own installations. External contributions and pull requests are **not currently accepted**. There is no public contribution review or support process at this time.

For local development, see the [README](README.md#development) and the relevant package documentation. The [security note](SECURITY.md) describes this fork's maintenance scope.

This policy applies to this fork only. The [original Flowise project](https://github.com/flowiseai/flowise) has its own policies; its maintainers are not responsible for this fork.

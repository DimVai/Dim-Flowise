# Custom Tool and Custom Function dependencies

This reference covers JavaScript running in the local NodeVM sandbox. An npm package must be installed where Flowise runs and allowed by the sandbox before a script can load it with `require()`.

## Configure additional dependencies

Use comma-separated names without spaces. For a local installation, set these variables in `packages/server/.env` and restart Flowise. In queue mode, apply the same settings to the workers that execute the flows and restart them. See [General server variables](../../CONFIGURATION.md#general-server-variables).

Allow only the packages and modules your scripts need. These settings apply to the local sandbox across Tools and Functions. The installed sandbox also blocks some built-in modules, including `vm` and `worker_threads`, even if listed. Avoid exposing `playwright` or `puppeteer` to the sandbox because their browser launch APIs can enable [code execution outside it](https://github.com/FlowiseAI/Flowise/security/advisories/GHSA-9gvv-qjj3-2p6g).

See the [upstream guide to importing dependencies](https://docs.flowiseai.com/integrations/langchain/tools/custom-tool#import-external-dependencies) for a Custom Tool example.

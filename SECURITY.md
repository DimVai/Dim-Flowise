# Security

This independent fork is maintained for the owner's own installations. It does not accept external vulnerability reports or offer a public security response process, response-time guarantee, bug bounty, or supported-version policy. Do not send reports about this fork to FlowiseAI.

Security issues relevant to this fork are monitored, and fixes are made when needed. See [Configuration](CONFIGURATION.md) for authentication, cookie, proxy, and persistence settings and the [changelog](CHANGELOG.md) for recorded changes.

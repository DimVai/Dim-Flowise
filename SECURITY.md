# Security policy

## Scope

This policy applies to this independent community fork. Flowise Cloud, other Flowise installations, and upstream releases are outside its scope.

The fork is maintained for personal use. It does not offer a bug bounty, guaranteed response times, or a supported-version policy for public releases at this stage.

## Reporting status

A private security reporting channel has not yet been established. This file will be updated with the reporting destination before the repository's first public publication.

Do not post credentials, personal data, or sensitive vulnerability details in public issues. FlowiseAI's security team is not responsible for reports about this fork.

## Maintenance

Relevant upstream or maintained-fork security fixes are considered individually for applicability, provenance, and license compatibility. The presence of a fix elsewhere does not mean it has been incorporated here. Adopted fixes and any required operator action are recorded in the [changelog](CHANGELOG.md).

See [Configuration](CONFIGURATION.md) for authentication, cookie, proxy, and persistence settings. Removing the commercial stack does not replace ongoing security maintenance of the community code and its dependencies.
